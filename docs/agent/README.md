# Навигация по документации для AI-агентов

Здесь хранятся инструкции и долгосрочный исследовательский контекст для AI-агентов, работающих с кодом. Корневой [AGENTS.md](../../AGENTS.md) намеренно короткий: редакторы и агенты автоматически находят его и переходят по ссылкам.

| Документ | Когда читать |
| --- | --- |
| [AGENT_GUIDE.md](AGENT_GUIDE.md) | Перед началом или проверкой любого тикета RQ1: порядок работы над одним тикетом и критерии остановки. |
| [CONTEXT.md](CONTEXT.md) | Когда нужно уточнить значения терминов candidate, attempt, gold equivalence и unknown. |
| [PROJECT_DECISIONS.md](PROJECT_DECISIONS.md) | При выборе архитектуры или изменении методологии: какие решения утверждены и почему. |
| [KNOWN_DUALIFY_LIMITATIONS.md](KNOWN_DUALIFY_LIMITATIONS.md) | При диагностике **оригинального Dualify/Z3** или обсуждении ограничений статьи: исходная методология должна сохраняться. |
| [KNOWN_BUGS.md](KNOWN_BUGS.md) | При диагностике ошибок и рисков **нашего расширения RQ1**, включая replay и восстановление после ошибок провайдера. |

Исследовательский план и задачи реализации отделены от этих инструкций: [спецификация RQ1](../rq1/SPEC.md), [протокол эксперимента](../rq1/PROTOCOL.md), [тикеты](../rq1/tickets/README.md).

**Разделение ответственности:** ограничения оригинального метода фиксируются в KNOWN_DUALIFY_LIMITATIONS, проблемы реализации RQ1 — в KNOWN_BUGS. Вместо повторного расследования используй перекрёстные ссылки.
